# Company source review candidate

This branch collects local authentication/terms, merchant integration, email,
privacy, operational-containment, website and dependency work for CI and review.
It does not authorize public service intake, paid billing, model use or deployment.

Private account records, personal test recipients, live resource presets and
local credentials are not published. Operator helpers contain sample identities;
they must not be connected to retained services without a separately reviewed
private configuration. The source-only email preset refuses live sending.
No existing provider credential was changed by preparing this branch.

The Standard CatVTON profile, model pins and serving quality settings remain
protected. AI dependency findings, commercial permissions, full staging,
independent assessment, GPU quality/isolation/capacity and pilot evidence remain
open. A successful CPU test is not public-launch approval. The AI audit remains
blocking; no new vulnerability suppression is introduced.

Evidence must identify the actual commit, image IDs, verifier and retained
artifacts. Operations notes and detailed company-account evidence stay private.
